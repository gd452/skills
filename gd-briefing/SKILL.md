세션 시작 시 프로젝트 현황을 한눈에 파악하고, 문서 간 불일치를 감지한다.

## 실행 절차

### 1. Git 상태 파악

```bash
git status
git log --oneline -5
git branch
```

- 미커밋 변경사항 요약
- 최근 커밋 5개 나열
- 미병합 브랜치 존재 여부

### 2. TODO.md 확인

- `[ ]` 미착수 항목 나열
- `[~]` 진행중 항목 나열
- 완료된 항목 수 / 전체 항목 수 (진행률)

### 3. MEMORY.md 확인

- `## 미결 사항` 항목 나열
- `## 현재 진행 상태` 요약
- `## 다음 TODO` 항목 나열

### 4. 교차 검증 (핵심)

MEMORY.md에 "완료"로 기록된 항목과 TODO.md 체크박스를 대조한다.

- MEMORY.md에서 "완료", "머지", "배포" 등의 키워드가 있는 항목 추출
- 해당 항목이 TODO.md에서 `[ ]` 또는 `[~]`로 남아있는지 확인
- **불일치 발견 시**: 목록으로 알림하고, TODO.md 갱신 여부를 사용자에게 확인

### 5. 장기 비전 (있는 경우)

- 프로젝트에 b3rys-vision.html 또는 유사 비전 문서가 있으면 핵심 방향 요약
- CLAUDE.md에 비전 문서 참조가 있는지 확인

## 출력 포맷

```
## 세션 브리핑

### Git
- 브랜치: {현재 브랜치}
- 미커밋: {N}건 — {요약}
- 최근: {커밋 1줄 요약 3개}

### TODO 진행률
- 완료: N개 / 전체: M개 (X%)
- 미착수: {항목 나열}
- 진행중: {항목 나열}

### 미결 사항
- {MEMORY.md 미결 항목 나열}

### 교차 검증
- {불일치 없음 | 불일치 항목 나열}

### 다음 작업 제안
- {MEMORY.md 다음 TODO 또는 우선순위 높은 미착수 항목}
```

## 주의사항

- 브리핑은 정보 제공만 한다. 코드 수정이나 파일 변경은 하지 않는다.
- 불일치 발견 시 자동 수정하지 말고, 사용자에게 알리고 확인을 받는다.
- TODO.md나 MEMORY.md가 없는 프로젝트는 해당 섹션을 건너뛴다.
