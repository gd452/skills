# Write Business Plan — 사업계획서 작성 스킬

Sequoia Capital 피치덱 템플릿을 기반으로, YC·a16z·Guy Kawasaki·한국 VC/정부사업 프레임워크를 통합한 사업계획서 작성 스킬.

## 트리거

- "사업계획서 써줘/만들어줘"
- "피치덱 작성/준비"
- "IR 자료 만들어줘"
- "투자유치 자료 작성"
- "business plan / pitch deck"
- 사업 아이디어를 설명하고 문서화를 요청할 때

## 워크플로우

### Step 0: 사전 정보 수집

사용자에게 다음을 질문하여 컨텍스트를 파악한다:

**필수 질문:**
1. **사업 아이디어**: 어떤 문제를 어떻게 해결하나요?
2. **용도**: VC IR / 정부지원사업 / 데모데이 / 엔젤투자 / 내부 검토 중 어디에 사용하나요?
3. **단계**: 아이디어 단계 / MVP 완성 / 트랙션 있음 중 어디인가요?

**선택 질문 (있으면 더 좋은 것들):**
- 타겟 고객은 누구인가요?
- 현재까지의 진행 상황 (트랙션, 매출, 사용자 수)?
- 팀 구성은?
- 투자 희망 금액은?
- 경쟁사로 인식하는 곳은?

→ 답변을 받으면 용도에 맞는 **변형 가이드**를 선택한다:

| 용도 | 장수 | 강조점 |
|------|------|--------|
| VC IR (발표용) | 10-12장 | 트랙션, 시장 규모, 팀 |
| VC IR (이메일용) | 15장 | 상세 설명, 자체 완결적 |
| 데모데이 | 5-7장 | 핵심만, 3분 기준 |
| 정부지원사업 | PSST 매핑 | 사회적 가치, 일자리, 기술성 |
| 엔젤투자 | 7-10장 | 비전, 팀, 열정 |

### Step 1: 시장 리서치 (선택적)

사용자가 시장 데이터를 충분히 가지고 있지 않다면, Agent 도구로 리서치 에이전트를 병렬 실행하여:
- TAM/SAM/SOM 추정
- 경쟁사 분석
- Why Now 근거 수집

WebSearch, WebFetch를 활용하여 실제 시장 데이터를 수집한다.

### Step 2: 섹션별 초안 작성

아래 15개 섹션을 순서대로 작성한다. 용도에 따라 선택/생략 가능.

---

#### 1. Cover — 한줄 소개
- 회사명 + 한줄 소개 (10단어 이내)
- 예: "Airbnb — 누구나 집을 공유할 수 있는 마켓플레이스"
- 작성법: [동사] + [대상] + [핵심 가치]

#### 2. Problem — 문제 정의
- **고객의 고통점**을 구체적으로 서술 (추상적 X)
- 현재 대안이 왜 부족한지 (기존 솔루션의 한계)
- 가능하면 **숫자로 문제의 크기** 표현
- 팁: "~하는 사람들은 ~때문에 고통받고 있다" 형식

#### 3. Solution — 해결책
- Problem에서 정의한 고통점을 **직접 해결**하는 방법
- 핵심 가치 제안 (Value Proposition) 1-2줄
- Problem → Solution 연결이 논리적으로 자연스러워야 함
- "우리는 [타겟]을 위해 [방법]으로 [문제]를 해결합니다"

#### 4. Why Now — 왜 지금인가
- 이 사업이 **지금** 가능하거나 필요한 이유
- 카테고리: 기술 변화 / 규제 변화 / 행동 변화 / 비용 변화
- 예: "스마트폰 보급률 95% → 모바일 우선 서비스 가능"
- Sequoia가 특히 중시하는 섹션

#### 5. Product — 제품/서비스
- 실제 제품 스크린샷, 데모, 또는 상세 설명
- 핵심 기능 3가지 (feature가 아닌 benefit 중심)
- 사용자 여정 (User Journey) 간략 설명
- MVP가 없으면 와이어프레임/목업이라도

#### 6. Traction — 견인력 (상황별)
- 매출, 사용자 수, 성장률, 주요 마일스톤
- **하키스틱 그래프**가 있으면 최고
- 없으면: LOI, 파일럿 결과, 대기자 명단, 고객 인터뷰 결과
- 아이디어 단계: 이 섹션 생략 또는 "검증 계획"으로 대체

#### 7. Market Size — 시장 규모
- **TAM** (Total Addressable Market): 전체 시장
- **SAM** (Serviceable Addressable Market): 도달 가능 시장
- **SOM** (Serviceable Obtainable Market): 단기 확보 가능 시장
- Top-down + Bottom-up 모두 제시
- VC 기준: SOM만으로도 최소 수백억 규모

#### 8. Competition — 경쟁 환경
- 2x2 매트릭스 또는 경쟁 비교 테이블
- "경쟁사가 없다"는 금지 — 대체재/간접 경쟁 포함
- 우리의 차별화 포인트 (Unfair Advantage / Moat)
- 경쟁 우위의 지속 가능성

#### 9. Business Model — 비즈니스 모델
- 수익 모델: 어떻게 돈을 버는가?
- 가격 전략: 얼마에 파는가?
- Unit Economics: CAC, LTV, LTV/CAC 비율
- 확장 가능성: 규모가 커지면 마진이 좋아지는가?

#### 10. GTM Strategy — 시장 진입 전략
- 초기 고객 확보 전략 (채널, 방법)
- 확장 전략 (Phase 1 → 2 → 3)
- 핵심 KPI 및 목표
- a16z가 특히 중시하는 섹션

#### 11. Team — 팀
- 핵심 멤버 2-4명의 프로필
- **왜 이 팀이 이 문제를 풀기에 적합한가?** (도메인 전문성)
- 주요 경력, 학력, 이전 창업 경험
- 부족한 역할이 있다면 채용 계획

#### 12. Financials — 재무 계획
- 3년 매출 전망 (연도별)
- 주요 가정(assumptions) 명시
- 손익분기점 시기
- 핵심 비용 구조

#### 13. Ask — 투자 요청
- 투자 요청 금액
- 자금 사용 계획 (비율 또는 항목별)
- 예: "5억원 투자 요청 — 개발 40%, 마케팅 30%, 운영 20%, 채용 10%"
- 다음 마일스톤: 이 투자로 달성할 목표

#### 14. Vision — 장기 비전 (선택)
- 3-5년 후 회사의 모습
- 확장 계획 (제품, 시장, 지역)
- 한국 VC/정부사업에서 특히 중시
- "우리가 성공하면 세상이 어떻게 바뀌는가?"

#### 15. Appendix — 부록 (선택)
- 상세 재무 모델
- 기술 아키텍처
- 특허/IP 목록
- 고객 추천서/사례
- 정부지원사업: 일자리 창출 계획, 사회적 가치

---

### Step 3: 문서 생성

용도에 맞는 형식으로 최종 문서를 생성한다:

**출력 형식 선택:**
1. **Markdown 문서** (.md) — 기본, 편집 용이
2. **HTML 프레젠테이션** — `/b3rys-design` 연계하여 웹 프레젠테이션

기본은 Markdown으로 작성하고, 사용자가 프레젠테이션 형식을 원하면 `/b3rys-design`을 활용한다.

### Step 4: 검토 (선택적)

사용자가 원하면 Agent 도구로 별도 검토 에이전트를 실행한다:
- VC 관점으로 각 섹션 평가 (10점 만점 스코어카드)
- Critical/Important/Nice-to-have 피드백
- VC 예상 질문 Top 5 생성

검토 에이전트의 프롬프트 예시:
```
당신은 시리즈A 투자 심사역입니다. 아래 사업계획서를 VC 관점에서 평가하세요.
각 섹션별 10점 만점 스코어 + 핵심 피드백 + 예상 질문 Top 5를 제시하세요.
```

### Step 5: 수정 및 완성

검토 피드백을 반영하여 최종본 완성.
사용자와 섹션별로 확인하며 수정.

## 작성 원칙

### 스토리텔링
- 전체 사업계획서가 **하나의 이야기**로 흘러야 함
- Problem → Solution → Why Now → Market → How → Who → Ask
- "왜?"를 3번 물어도 답할 수 있는 깊이

### 간결함 (Kawasaki 원칙)
- 한 섹션에 하나의 핵심 메시지
- 불릿포인트 활용, 장문 지양
- 숫자와 데이터로 말하기

### VC 관점
- 투자자가 알고 싶은 순서로 배치
- "이 팀이, 이 시장에서, 이 방법으로, 큰 돈을 벌 수 있는가?"
- 모든 주장에 근거(데이터, 사례) 첨부

### 한국 시장 특화
- 국내+해외 시장을 모두 다루기
- 정부지원사업 대응 시 PSST 프레임워크 매핑
- 사회적 가치, ESG 요소 자연스럽게 포함
